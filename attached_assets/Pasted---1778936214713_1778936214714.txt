يا وكيل، قم بدمج وتفعيل الأدوات والخدمات العالمية المجانية التالية داخل أقسام ومحاور التطبيق فوراً، مع الاعتماد الكامل على البرمجيات المفتوحة المصدر والخطط المجانية لضمان (صفر تكلفة وصفر رصيد) عليّ:

1. تصميم المواقع وقوالب التطبيقات (Web & App Builders)
HTML5/Tailwind Components: برمجة معالج داخلي يولد أكواد مواقع كاملة وقوالب تطبيقات جاهزة ومستجيبة (Responsive) باستخدام مكتبة Tailwind CSS برمجياً وبشكل مجاني 100% دون الحاجة لأي API خارجي.

GitHub API: ربطه بخطة مجانية لرفع وحفظ مشاريع ومواقع المستخدمين البرمجية مباشرة كاستضافة مجانية.

2. العروض التقديمية والملازم والكتب (PowerPoint & Documents)
Python-PPTX & DOCX Libraries: تنصيب مكاتب البرمجة الداخلية (python-pptx) و (python-docx) لتوليد ملفات بوربوينت احترافية وعروض تقديمية، وتجهيز كتب وملازم دراسية كاملة بصيغة PDF ووورد بضغطة زر مجاناً من السيرفر.

Gutenberg & Open Library APIs: ربط المكتبات المفتوحة المجانية لجلب وتوفير آلاف الكتب والملازم الجاهزة للمستخدمين مجاناً.

3. تصميم الجرافيك والأنمي (Images & Designs)
Hugging Face Inference API: ربط النماذج المجانية لتوليد الصور والأنمي مثل (Stable Diffusion XL أو Flux.1-Schnell) عبر سيرفرات Hugging Face المجانية بالكامل وبدون أي فواتير.

Pollinations AI: دمج الـ API المجاني والسريع جداً لتوليد الصور والتصاميم فظياً وبدون أي رصيد.

4. الصوت والموسيقى والفيديو (Audio, Music & Video)
Hugging Face TTS (Space APIs): استخدام محركات تحويل النصوص إلى صوت (Bark أو Coqui TTS) المفتوحة والمجانية لتوليد أصوات طبيعية دون الحاجة لـ ElevenLabs المدفوع.

Audiocraft (by Meta): برمج محركاً داخلياً لتوليد الموسيقى والخلفيات الصوتية القصيرة مجاناً عبر الأكواد المفتوحة.

FFmpeg Engine: دمج أداة المعالجة الداخلية لتعديل مقاطع الفيديو، دمج الصوت مع الصور، وقص الفيديوهات برمجياً داخل السيرفر بصفر تكلفة.

5. نظام الربط والتشغيل (Zero-Cost Policy)
يُمنع استخدام أي أداة تتطلب رصيداً أو دفعاً بالدولار. اعتمد على الأكواد والمكتبات الداخلية (Local & Open Source) لتقديم محتويات جاهزة وسريعة فوراً للمستخدم.

نفذ الربط والبرمجة لهذه الأدوات الآن واجعلها تظهر في محاور الخدمات داخل واجهة 'يمن شات'!"
